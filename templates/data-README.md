# Put the {{dataset}} data files here

Everything goes in this one folder. Subfolders are fine: you can unzip a
UK Data Service download into it as it is.

The scripts find each file by name, whatever its format — `.tab`, `.dta`
(Stata), `.sav` (SPSS) or `.csv`. These are the ones this selection needs:

{{files}}

Get them from the UK Data Service: {{ukds_url}}

Nothing in this bundle contains study data, and nothing writes to this folder.
